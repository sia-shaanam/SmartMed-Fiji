# Smart Med Fiji Patient Tracking Software

Welcome to the Smart Med Fiji Patient Tracking Software project. This software was built as part of an academic group project to improve patient tracking, streamline healthcare workflows, and enhance communication between healthcare professionals in Fiji.

---

## 📌 About the Project

I built this system with my team to address challenges in managing patient data in healthcare facilities. With this software, healthcare providers can:

- Register and admit patients efficiently
- Track patients in real time throughout their treatment
- Schedule appointments and manage clinical workflows
- Share information securely across departments
- Generate analytical reports for better decision-making

## 🎯 Purpose & Scope

### Purpose

The goal of this system is to improve the efficiency and effectiveness of healthcare delivery in Fiji through:

- Real-time patient tracking
- Data-driven care coordination
- Streamlined admin processes
- Secure, compliant patient data management

### Scope

The system supports:

- Patient registration and admission
- Appointment scheduling
- Real-time updates on patient status
- Integrated data access across departments
- Reporting, analytics, and monitoring tools
- User training and support

---

This project was inspired by research on:

- Electronic Health Record (EHR) systems
- Health Information Exchange (HIE) models
- Telemedicine practices
- Patient journey and care coordination frameworks

---

## 📝 Glossary Highlights

- **EHR**: Digital record of a patient’s medical history
- **Interoperability**: Seamless data exchange across systems
- **Patient Portal**: Online platform for patient access
- **Care Coordination**: Collaboration among healthcare teams
